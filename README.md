# 사이 / SAI STUDIO

별자리·사주·자미두수 사이트의 전체 애플리케이션 소스입니다. 디자인, 이미지, 폰트, 계산, PDF 다운로드, 모임 신청, 체험 기록, 결과 발송 신청 및 운영자 관리 코드를 보존합니다. 개인정보·실제 신청 기록·운영용 비밀키·로컬 DB·이전 Git 이력은 포함하지 않습니다.

## 상태

코드 보관과 사이트 실행은 별개입니다. GitHub Pages에서 신청/관리 기능까지 실행하도록 이전한 상태가 아닙니다. 기존 운영 사이트·DB·로그인·권한·발송 설정은 변경하지 않습니다. 새 주소 유지에 필요한 선행 조건은 [MIGRATION-REVIEW.md](MIGRATION-REVIEW.md)를 참고하세요.

## 보존된 모든 화면

- `public/experience/index.html`: 메인, 성향 계산, 상세 보고서, 모임 신청 팝업
- `public/experience/operators.html`: 통합 운영자 관리
- `public/experience/participants.html`: 체험·신청 기록
- `public/experience/admin.html`: 기존 발송 관리 주소의 호환 이동
- `public/experience/join.html`: 기존 모임 신청 주소의 호환 이동

5개 HTML 페이지·CSS·JavaScript·폰트와 `app/`, `lib/`, `db/`, `worker/`의 기능 코드는 원본과 바이트 단위로 동일합니다. 사용 중인 PNG 5개는 숨은 서명/인증서 메타데이터(caBX)만 제거했으며, 원래 IHDR·IDAT·IEND 바이트가 동일한 것을 검증해 이미지 픽셀과 시각적 내용을 유지했습니다. 제거된 서명 메타데이터로 원본 출처 인증을 주장하지 않습니다. 현재 코드에서 참조하지 않는 옛 사진 `garden.jpg`, `journal.jpg`, `pottery.jpg` 3개도 개인정보 메타데이터를 공개하지 않도록 제외했습니다. 실제 화면에 쓰는 이미지·폰트·5개 페이지는 보존합니다. DB의 실제 신청 기록은 소스가 아니며 이 저장소는 운영 데이터 백업을 포함하지 않습니다.

## 실행 환경과 비밀 설정

Node.js 22.13 이상, Vinext/Vite, Cloudflare Workers와 D1 환경을 사용합니다. 현재 운영자 인증은 Sites 호스팅 계층이 검증하는 ChatGPT 신원에 의존합니다. 임의의 요청 헤더로 관리자 신원을 대체하거나 인증을 우회하지 마세요.

기존 Sites에서 로컬 실행을 준비할 때 `.openai/hosting.example.json`을 `.openai/hosting.json`으로 복사하고, 본인에게 권한이 있는 프로젝트 설정을 로컬에서만 복구해야 합니다. 기존 배포의 프로젝트 식별자와 로컬 편집기 설정은 제외했습니다. 필요한 변수 이름은 실제 값이 비어 있는 `.env.example`에 있습니다. 실제 값은 호스팅의 비밀 환경 설정에만 보관하세요.

의존성 설치 후 `npm run dev`/`npm run build`를 사용할 수 있지만, 다른 호스팅에서는 인증·DB·런타임 어댑터를 먼저 구성해야 합니다. Pages에 복사하는 것으로 API 서버가 실행되지는 않습니다.

`.env`, `.dev.vars`, 로컬 DB, CSV, 로그, QA 캡처, 실제 사용자 보고서/PDF와 API 키를 커밋하지 마세요. 원본 운영 문서의 개인 문의 이메일은 예약 예시 주소로 바꿨습니다. 테스트의 가상 연락처는 운영 데이터가 아닙니다.
